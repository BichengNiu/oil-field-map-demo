## 页面更新与截图

页面首开仅使用本地PortWatch事实、目录和AIS档案，不自动访问数据源；本地数据缺失时提示点击对应刷新按钮。点击“刷新港口数据”会更新PortWatch目录、日期及活动数据；点击“刷新船舶数据”会查询一次Open Waters并归档有效报告；海域历史交付源仅在“刷新海域历史数据”点击时同步。打印报告和风险运力读取本地缓存，不会暗中触发上游查询。获取失败显示来源不可用，不把缺报当成零。

“地图”页仅显示各源的最新数据：港口与咽喉点分别使用自己的最新观测日，船舶图层显示当前AIS快照；缺报保持未知。港口页按最新有效日期显示日活动及7/30日窗口指标，油气信息保留原披露日期。港口与咽喉点的历史数据可在“数据下载”页按日期范围获取。

地图右上角“保存地图 PNG”下载当前视野、已勾选监测图层、图例、日期、打开的弹窗和底图署名。底图须加载完成；浏览器需要允许地图组件下载文件。底图或截图组件加载失败时显示原因并允许重试。

### 打印报告

报告在页面后台准备；使用 Streamlit 工具栏的 Print 或浏览器打印时，打印样式自动隐藏页面控件及普通页面内容，只输出完整报告，不需要单独开关或下载 HTML。地图监测卡仅读取本地历史事实，不会在刷新或页面载入时下载历史。只有点击“准备打印报告”才按需获取90日窗口和去年同期窗口；7天内已核验的窗口缓存会复用，PortWatch日度事实更新后仅覆盖窗口内较新的本地记录。报告 HTML 在输入不变的15分钟内复用，准备后会在后续页面操作中保留；读取失败会显示来源和错误，便于再次点击重试。报告包含 Esri 地图底图、监测范围和符号图例、港口和咽喉点运输趋势、资产披露表、AIS快照及数据口径说明；缺报数值留空。补充名录港口不作为独立统计点。



### 港口与咽喉点数据下载

“数据下载”页默认选择全部项目节点，也可单独筛选导出范围和数据类型；水域、国家和节点多选均提供互斥的“全选”项。下载每个节点自己的最新日、指定UTC日期区间或全部可用历史。历史统计起点为2019-01-01；以节点目录及源站逐节点日期范围为准，节点未覆盖的日期不会补造记录。页面下载按钮生成CSV、适合不超过2万行的Excel工作簿，或完整ZIP（含按年和节点块拆分的CSV、节点目录、缺报区间、指标字典、来源查询和UTC生成时间）。大于2万行的结果直接分块写入临时ZIP并只保留下载路径，降低Streamlit会话内存占用。港口表可一键跳转到所列港口的全历史下载。

导出只包含IMF PortWatch发布的港口／咽喉点日度汇总指标，这些指标由AIS信号估算；不是逐船位置或完整AIS航迹。0保留为源站报告的零值，空值和无记录日期继续缺失；ZIP覆盖表报告各节点记录数及缺报区间。取数先按源站日期分块分页，再核对分页行数与源站总数；不一致时停止生成。只有点击“生成下载数据”才访问PortWatch；历史窗口缓存24小时，窗口内有较新的已校验日度事实时合并本地更新。导出只强制重读最近7天；旧历史段按24小时缓存读取，避免因当前年份含近期数据而整年重取。港口进口／出口估算货量以公吨记录，咽喉点capacity以载重吨记录，两者不能直接混作实际贸易量。再分发须遵守IMF PortWatch来源条款。

### AIS船位归档

Streamlit页面不会后台轮询Open Waters，也不会自动连接AISStream。点击“刷新船舶数据”时查询Open Waters一次，将有效报告归档到统一DuckDB；地图、船舶表和CSV显示本地最近两小时的船位快照。海域卡只读取本地确认的进入事件累计。

设置服务器环境变量或Secrets的 `MONITORING_DB_PATH` 可将统一数据库写入持久磁盘；默认项目下 `runtime/monitoring.duckdb`。旧 `AIS_ARCHIVE_PATH` 仅用于只读迁移原档案。只有明确观测时间的船位进入档案，接收时间单独保存，不伪造报告时间。项目内的独立 `collector.py` 服务仍支持显式持续采集；手动刷新部署不要运行它。

另有一份[公开岸基AIS档案](https://huggingface.co/datasets/yasumorishima/hormuz-ais)，覆盖2026-03-14至2026-04-11，样本主要来自迪拜附近，并非霍尔木兹或五水域全量历史，也不用于计算通行总量。源数据审计见 [AIS_HISTORY_SOURCE_AUDIT.json](AIS_HISTORY_SOURCE_AUDIT.json)。

`timestamp` 是上游历史报告时间（原文件为无时区UTC），用于选日；原文件 `received_at` 是采集器接收时间，另存 `provider_received_at`，不会拿下载时间或采集时间替代报告日。静态字段仅采用对应历史行，不借用今天资料。下载固定版本和内容散列，字段、坐标、时间或校验失败不标记成功。

原数据许可标为 `other/see-source-terms`，发布者并未授予无条件再分发许可；原文件、数据库和逐条数据不提交公开仓库，使用及再分发须遵守AISStream来源条款。

如需更完整的指定区域历史，应索取实际日期和水域的覆盖样本及授权：[VesselFinder](https://www.vesselfinder.com/historical-ais-data)提供2009年以来自定义区域的卫星/岸基历史CSV；[Datalastic](https://datalastic.com/historical-location-ais-data-api/)提供按地点、半径和历史时段枚举船舶的报告API（须密钥/订阅）。单船轨迹API无法发现所有历史过境船舶，应优先区域查询，核查缺报及卫星覆盖，不能把供应商“全球”营销文案当成具体海峡完整性保证。

## 当前功能

- 地图默认显示全部监测图层：可定位油气资产、全部港口、全部咽喉点和当前有效 AIS 船位。港口与咽喉点分别读取 PortWatch 最新可用日，在紫色六边形 popup 中显示总通过船舶数、估算承载货量，以及集装箱、干散货、普通货物、滚装、油轮/液货五类分项。
- AIS 船位在地图中按航向旋转，颜色区分油轮/液货船、货船和其他/未知船型；低缩放级别聚合密集船位，放大地图可查看单船图标。页面不再提供地图、港口、船型或油气筛选；完整本地船位档案和资产目录默认显示，数据页仍可指定导出范围。只有点击“刷新船舶数据”才查询Open Waters并供地图、船舶页和打印报告读取；API密钥不会下发到浏览器。
- 港口 popup 和“港口”表提供港口活动指数、船型结构、活跃天数率、单船平均货量、进出口平衡指数，并保留所选日有效进港艘次和估算装卸量；较慢的历史风险运力在“港口”表中按需读取。
- 打印报告的监测范围图使用 Esri 街道底图，港口用紫色小六边形、咽喉点用紫色空心圆、油气资产用黑色小三角、船舶用红色实心圆点；船舶位置按地图网格聚合。
- 油气页显示完整公开资产目录；油气使用橙色菱形，产量、产能、目标及未披露数值在弹窗和表格中明确区分。缺少独立点位时可使用组成油田几何中心、公开设施点或最近上级代表点，并在 popup 中注明精度和坐标证据。区域／设施代理点采用虚线边框，与精确点位视觉区分。
- 底图固定使用 Esri 街道图且不显示底图选择框。
- 港口目录、日活动、窗口指标、风险运力和咽喉点请求分别缓存；页面首开仅读本地值，PortWatch 请求由刷新按钮或“准备打印报告”按钮触发。Open Waters 只在点击刷新时查询并归档一次，地图弹窗按需生成，船位年龄在页面中计算。船位确定视野后分批聚合绘制，地图必需的 Leaflet 脚本和样式随项目提供，避免等待外部 CDN；底图仍由 Esri 提供，截图组件在点击时加载。地图重绘会恢复用户视野及打开的标记弹窗；打印报告使用完整输入内容的 JSON 校验复用 HTML，报告窗口按需联网并使用已验证历史缓存。

## 手动 AIS 刷新与运行方式

点击“刷新船舶数据”时，应用查询无需密钥的 [Open Waters 开放 AIS 网络](https://openwaters.io/ais/)；覆盖受公开feed和接收站分布影响。查询四海域及边界观测带、苏伊士与曼德海峡，按免费额度拆成四组请求，并在表格／船舶弹窗保留来源及署名。查询矩形只限定采集范围，海域进入次数按固定IHO多边形识别。扩大范围不保证上游存在接收站或近期报文。数据按各上游来源自己的许可条件提供。当前Streamlit页面不自动连接AISStream；独立采集服务仍可单独配置和运行。

```bash
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
```

该配置仅用于显式运行独立采集服务；Streamlit页面不会使用 AISStream 密钥建立后台连接。

真实密钥文件已被 `.gitignore` 排除，不要提交到 GitHub。页面未配置密钥也会在手动刷新时尝试Open Waters；如果该源无数据，页面会显示状态，不能把未收到船位解释为0艘。油气、PortWatch港口和咽喉点仍可正常使用。

当前Streamlit页面不会运行AISStream WebSocket连接。若单独运行 `collector.py` 常驻采集服务，AISStream才会按配置建立连接和重连；这不属于页面手动刷新模式。页面只展示最近两小时的本地有效船位；不把缺报解释为0艘或静止。Open Waters的免费查询结果可能受区域额度影响；来源署名会保留在船舶表、弹窗和数据源说明中。

## 数据范围

港口点位来自 [IMF PortWatch 当前港口数据库](https://services9.arcgis.com/weJ1QsnbMYJlCHdG/arcgis/rest/services/PortWatch_ports_database/FeatureServer/0)，每日港口船次及装卸量来自 [每日港口活动](https://services9.arcgis.com/weJ1QsnbMYJlCHdG/arcgis/rest/services/Daily_Ports_Data/FeatureServer/0)。项目用 `portwatch.py` 中五个公开经纬度框定义波斯湾、阿曼湾、霍尔木兹海峡、苏伊士运河和曼德海峡“附近”，交叠区域按字典顺序唯一归属。它覆盖 PortWatch 数据库落入这些范围的全部唯一港口点，不等于当地全部实际泊位、油码头或未被 PortWatch 收录的设施。

咽喉点目录及每日通行数据分别来自 [PortWatch 咽喉点数据库](https://services9.arcgis.com/weJ1QsnbMYJlCHdG/arcgis/rest/services/PortWatch_chokepoints_database/FeatureServer/0) 与 [每日咽喉点活动](https://services9.arcgis.com/weJ1QsnbMYJlCHdG/arcgis/rest/services/Daily_Chokepoints_Data/FeatureServer/0)。港口日期和咽喉点日期独立显示，避免把更新节奏不同的数据强行对齐。

截至2026-09-30 UTC复核，PortWatch点位源包含2,065个港口，项目五区筛出63个统计点；最新港口日活动为2026-09-25，63点均有当日源记录。补充33个有原始名录、无独立活动统计的点位后，完整名录为96点。三个咽喉点最新日活动为2026-09-27。数据会随源站更新，应用默认读取实时最新可用日期。

## 指标口径

| 指标 | 计算 | 解释 |
| --- | --- | --- |
| 港口活动指数 | 当前 7/30 日窗口有效进港艘次 ÷ 前一等长窗口艘次 × 100 | 100 表示持平；基期为 0 或任一窗口不完整时留空 |
| 船型结构 | 窗口内各船型进港艘次 ÷ 全部进港艘次 | 五类占比在有活动且数据完整时合计为 100% |
| 活跃天数率 | 窗口内进港艘次大于 0 的天数 ÷ 窗口天数 × 100% | 衡量活动连续性，不以单日零值替代趋势 |
| 单船平均货量 | 窗口内估算进口量与出口量之和 ÷ 有效进港艘次 | 单位万吨/艘次，属于 AIS、吃水和载重能力估算 |
| 进出口平衡指数 | `(出口量 − 进口量) ÷ (出口量 + 进口量) × 100` | −100 为完全进口导向，+100 为完全出口导向 |
| 风险运力 | 该港所有出港航线 `daily_capacity_at_risk` 合计 | 单位万吨/日；基于 2019—2024 航线网络的历史冲击暴露，不是实时船位 |

PortWatch 的 `portcalls` 是进入港界并满足其贸易挂靠筛选的有效进港艘次，不是在港船舶存量，也不能直接还原离港数或平均停泊时长。单日 0 表示源表当日确实记录为 0；缺报、窗口不完整和不可计算值保持为空。`tanker` 可能包含原油、成品油和其他液体货物，不应解释为分油种实测吞吐量。

## AIS 口径与限制

- 实时位置、航速和方向来自 [Open Waters AIS 聚合网络](https://openwaters.io/ais/)及可选的 [AISStream WebSocket API](https://aisstream.io/documentation)，与 PortWatch 日度汇总是独立数据源，不能用实时地图点数反推 PortWatch 的港口挂靠指标。船舶页按五个监测水域及红海北、南段分别列出两路来源的当前船位数；上游未返回报文不代表该水域没有船舶。Open Waters 按每条上游 feed 的许可条件提供数据，因此界面保留 API 返回的来源署名。
- 地图默认显示 AIS 船位图标；PortWatch 的霍尔木兹、曼德海峡和苏伊士运河日通行艘次使用紫色咽喉点标记及日度详情弹窗。PortWatch 没有独立的红海中段通行总量，因此红海水域显示 AIS 船位，咽喉点统计分别显示在苏伊士和曼德两端。
- 动态位置消息与静态船舶资料按 MMSI 合并。基础 AIS 船型代码可识别油轮／液货船、货船、客船等大类，但不能可靠区分集装箱船、干散货船、原油油轮和成品油轮；这些细分类需要商业船舶主数据补充。
- 表中的 AIS 报告时间来自上游报文或 Open Waters 的最近报告时间（UTC），不是 PortWatch 日度统计时间。AIS 是事件驱动广播，点位可能受岸基／卫星覆盖、网络延迟、设备关闭、错误 MMSI 或位置欺骗影响；它不是全部船舶的完整普查。
- 应用只把标准化后的最新船位快照发送给浏览器，不发送 API Key 或原始 WebSocket 流。AISStream 当前不提供 SLA 或历史重放，重要研究需要自行持久化原始报文或改用带历史服务的商业数据源。

## 油气层级口径

- 底层目录包含692项公开命名资产，当前483项可绘制、209项仅列目录。未核实的区域、设施、上级代表点与组成资产几何中心已撤回地图；地图只显示采用的资产/具名井点位，弹窗及导出继续保留来源坐标精度。
- 油田群／区块有来源直接披露值时使用上级值，组成单田不求和、不重复计入。Ghawar 按官方组成区域列为油田群；Khurais 综合体包含来源明确列出的 Khurais、Abu Jifan、Mazalij 和 Qirdi。
- Rumaila 作为有田级实际产量和坐标的主力独立田标记为战略层级。没有可靠田级数值但具有区域代表性的少量主力田也采用该标签，数值标为未披露；地图与油气页仍显示全部可定位资产。

- 坐标优先采用有具名证据的WGS84资产点位；田级近似点和具名钻井按来源精度明示。仅有区域、设施、上级资产点或组成点均值时，资产保留在目录中，不以回退位置绘制地图。
